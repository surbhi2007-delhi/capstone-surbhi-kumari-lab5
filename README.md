## Project Overview

Roamora is a responsive travel agency website developed as a capstone project for Web Development Lab 5.

The website is designed to provide visitors with an attractive and user-friendly platform to explore travel destinations, discover holiday packages, learn about the travel brand, and submit travel inquiries.

The project focuses on creating a modern frontend using HTML, CSS, and JavaScript.

## Project Objectives

- To develop a structured and responsive website.
- To understand the practical implementation of HTML5 and CSS3.
- To create an attractive user interface for a travel agency.
- To implement responsive layouts using Flexbox, Grid, and media queries.
- To improve frontend development and design skills.

## Features

- Modern and attractive homepage.
- Navigation bar with different website sections.
- Hero section with a travel-themed background.
- Destination cards with category filters.
- Holiday package section.
- About Roamora section.
- Travel inquiry form.
- Responsive layout for desktop, tablet, and mobile devices.
- Interactive navigation menu.
- Hover effects and CSS animations.

## Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layout, responsiveness, and animations.
- JavaScript – Interactive elements and basic functionality.

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Open the file in a web browser.
5. Explore the different sections of the website.

## Responsive Design

The website uses CSS media queries to adjust its layout according to different screen sizes.

- Desktop: 1024px and above
- Tablet: Around 768px
- Mobile: 480px and below

The layout adapts to smaller screens to provide a better browsing experience.
